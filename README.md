# dots.rhr

My uncle's 2009 tower came to me in 2020. I was fifteen, in class nine, when it arrived. 2GB RAM with Pentium CPU. I replaced Windows 7 with Windows 10 anyway as Microsoft listed 2GB as minimum. I wanted the latest apps. It crawled.

I put Fedora 33 on it. Between 2020 and 2023 I did distro hopping but stayed on Fedora. Fresh without breaking, clean without fuss.

I got a new build in January 2023 containing AMD iGPU. Fedora 38 through 42 ran clean.

Fedora 43 broke that. Freezes, Wayland stutter, corruption, black on boot. Even the live USB failed. I moved to Arch within a week.

I still love GNOME. It is well made. I love its craft. But, as AI apps get heavier each month and RAM costs keep climbing. I needed headroom when the desktop stays quiet.

GNOME is a furnished apartment. This is a bare studio I measured myself, a new setup for me. Makes my system take less memory.
